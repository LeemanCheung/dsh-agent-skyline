## Design Context

### Users
DeepSeek Harness developers who want to understand how an Agent session evolved, replay the work as a city, and export a privacy-safe visual artifact. They use Agent Skyline inside the existing DSH conversation workspace, so the plugin must feel native rather than like a separate game overlay.

### Brand Personality
Precise, optimistic, crafted, and local-first. The interface should communicate trustworthy engineering and quiet delight, not cyberpunk spectacle.

### Aesthetic Direction
A DSH-native light workspace with softly blue-tinted paper surfaces, crisp cobalt interaction accents, restrained mint/amber/coral semantic colors, and an architectural illustration style inspired by premium editorial infographics and contemporary model-making. Avoid black modal surfaces, neon cyan-on-dark treatments, purple gradients, nested dashboard cards, repetitive cyan blocks, and decorative glow.

### Design Principles
1. Inherit DSH theme tokens for every shell surface, border, label, state, and action so the plugin belongs to the host in both light and dark mode; light mode is the visual baseline.
2. Make the procedural city the single visual anchor. Controls stay quiet and compact around it.
3. Encode session categories through architectural form, roof detail, landscape, and window rhythm, not only color.
4. Keep every generated city deterministic, lightweight, accessible, privacy-safe, and exportable as self-contained SVG/PNG.
5. Use purposeful motion for construction and state changes only, with full reduced-motion support.
